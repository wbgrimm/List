IXD‑404 · Week 05 · Dan Park

List, built as one system, run through an ASCII lens

A single structural grid—left slot, one or two lines of text, a trailing slot, navigate or expand—rendered twice, in two tones, against a live generative backdrop instead of a flat color: a continuously‑computed stable‑fluids solver (Stam’s method: diffuse → project → advect), not a video or a loop, rendered as hard‑pixelated monospace density characters. Your cursor doesn’t paint it, it interrupts it — parting the field like wiping condensation off glass. Tap a row to navigate; tap the last row to expand it.

Brief coverage

  • Left slot: icon / avatar / thumbnail / none
  • One line and two‑line text
  • Trailing text / icon / both
  • Navigate action (push) & expand action (reveal)
  • Default, hover & pressed states
  • Spec below each prototype — no separate Figma file

Why these count as one system, not two apps: every row in both sets is built from the same parts — left slot (icon / avatar / thumbnail / none), a one‑ or two‑line text block, a trailing slot (text / icon / both), and a chevron or caret for navigate vs. expand — at identical padding, gaps and row heights. Tone lives in radius, stroke, color and type, same as any static system — but it also extends into what the background itself is doing: a field you can refill with color vs. a current you can only ever interrupt, while the row grid underneath never moves.
